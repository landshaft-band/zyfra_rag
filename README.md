# RAG-помощник «Цифра. Диспетчер»

Учебный проект по техподдержке. Помощник отвечает по синтетической документации и решённым тикетам, показывает источники и запрашивает уточнения, когда данных недостаточно.

## Маршрут запроса

`FastAPI → Guardrails → PostgreSQL/outbox → Kafka → Redis Streams → воркер`

Воркер учитывает историю диалога, ищет фрагменты в Qdrant через E5 и BM25, объединяет выдачу через RRF и удаляет дубли. Для запросов документов поиск учитывает заголовки разделов. LLM-реранкер отбирает подходящие фрагменты, затем модель составляет ответ со ссылками. Веб-клиент опрашивает API, пока задание обрабатывается.
